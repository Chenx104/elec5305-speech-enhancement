# Sources, software and redistribution

- **LibriSpeech:** V. Panayotov, G. Chen, D. Povey and S. Khudanpur, ICASSP 2015. [Official corpus page](https://www.openslr.org/12/) lists CC BY 4.0. The project uses test-clean and dev-clean. Corpus speaker/utterance IDs in manifests identify public research recordings, not participant names.
- **DEMAND:** J. Thiemann, N. Ito and E. Vincent, [Zenodo record 1227121](https://zenodo.org/records/1227121). The archived API says CC BY 4.0, while the record description and accompanying DEMAND document say CC BY-SA 3.0. This inconsistency remains unresolved. The package redistributes neither original nor mixed audio; its example spectra are derived analytical visualizations with this attribution. Check applicable terms before publishing any audio, including audio in a video. The preserved audit is `protocol/SOURCE_AND_LICENSE.md`.
- **Babble:** four-reader mixtures generated from assigned LibriSpeech readers. The same speech-source attribution applies. No babble waveform is included.
- **DeepFilterNet3:** H. Schröter, T. Rosenkranz, A. N. Escalante-B. and A. Maier, *DeepFilterNet: Perceptually Motivated Real-Time Speech Enhancement*, arXiv:2305.08227. [Upstream software](https://github.com/Rikorose/DeepFilterNet), v0.5.6 executable and pinned model archive. Upstream software license texts are retained under `protocol/DeepFilterNet_LICENSE*.txt`; the executable and weights are downloaded separately, not relicensed here.
- **SpeechBrain ECAPA:** [model card](https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb), revision `0f99f2d0ebe89ac095bcc5903c4dd8f72b367286`. The card identifies Apache-2.0. SpeechBrain is external software; ECAPA-TDNN is described by B. Desplanques, J. Thienpondt and K. Demuynck, Interspeech 2020. No weights or embeddings are redistributed.
- **VOICEBOX:** Mike Brookes / Imperial College London, [sap-voicebox](https://github.com/ImperialCollegeLondon/sap-voicebox), pinned commit `a8916a8e87294ebd052b91a1f50e196351b3e561`. It supplies minimum-statistics tracking and the external implementation comparison. The inspected function header identifies LGPL-3.0-or-later. No VOICEBOX source is bundled; retain upstream notices when obtaining it.
- **MATLAB, toolboxes, Python libraries:** separately licensed dependencies. MATLAB is proprietary and is not included. Python environment versions are recorded in `protocol/requirements.lock.txt`.

This preparation does not impose a new blanket license on student work, datasets or third-party components. Existing notices remain applicable. The student completes the AI assistance declaration in the separate report; this package does not invent a declaration on the student's behalf.
